# Student Performance Data Analysis

## Project Overview
This project analyzes student academic performance using Python. It explores attendance, daily study hours, and subject-wise marks to identify patterns and summarize student performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Information
- Total Students: 200
- Total Columns: 9
- Dataset Type: Synthetic Data

## Project Features
- Dataset creation and management
- Data inspection and cleaning checks
- Statistical analysis
- Subject-wise average marks
- Attendance analysis
- Study hours vs marks analysis
- Correlation analysis
- Student performance categorization
- Data visualization

## Visualizations
1. Subject-wise Average Marks (Bar Chart)
2. Attendance Distribution (Histogram)
3. Study Hours vs Average Marks (Scatter Plot)
4. Correlation Heatmap
5. Performance Category Distribution (Pie Chart)

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open the Jupyter Notebook.
4. Run all cells sequentially.

## Note
This project uses synthetic student data for educational and demonstration purposes only.
